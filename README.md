# Nebula Hub — Nebula Labs

Versão completa de frontend do Nebula Hub.

## Arquivos
- `index.html` — estrutura do site
- `style.css` — visual responsivo
- `script.js` — navegação, dashboard e interações

## Importante
Esta versão é um frontend demonstrativo. Os dados exibidos no dashboard são fictícios.
Ela ainda não possui autenticação Discord, API ou conexão real com o NebulaBot.

## Publicar no GitHub Pages
1. Substitua os arquivos antigos pelos três arquivos deste projeto.
2. Faça commit/push para o repositório.
3. Em Settings → Pages, mantenha a publicação pela branch configurada.
4. Depois configure o domínio personalizado no GitHub Pages.
